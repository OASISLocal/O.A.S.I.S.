EDICIÓN WEB · VIGENTE DESDE EL 20 SEP 2026

Política de privacidad.

Ámbito. Esta política cubre únicamente la web de O.A.S.I.S., el Journal, la documentación pública, los mensajes de contacto y la lista de espera de Max. No describe la aplicación de escritorio; su documentación se publicará por separado.

Proveedores

GitHub Pages aloja la web. La homepage puede consultar la API pública de GitHub. La lista de espera usa un Worker y KV configurados por O.A.S.I.S. en Cloudflare. Estos proveedores pueden procesar datos técnicos bajo sus propias políticas.

Retención y derechos

La preferencia queda en tu navegador hasta que borres los datos. Conservamos la lista de espera hasta completar el aviso o recibir una solicitud de eliminación. Puedes pedir acceso, corrección, eliminación o restricción escribiendo a hello@oasislocal.dev.

Sin publicidad

No usamos Google Analytics, píxeles publicitarios ni SDKs de analítica. La política puede actualizarse cuando cambien la web o sus proveedores.

Consulta también el EULA web y los avisos de terceros.
