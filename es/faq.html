Inicio / FAQ

Preguntas, respondidas sin humo.

¿Funciona sin internet?

Las funciones locales compatibles pueden funcionar después de instalar un modelo. Búsqueda web, clima, páginas online e integraciones externas necesitan red.

¿Necesito una cuenta?

No para la experiencia Personal actual.

¿Puedo usar mi propio modelo?

Puedes probar modelos GGUF compatibles. La compatibilidad depende del modelo, cuantización, contexto y hardware.

¿Qué incluye Personal?

Chat local, voz, memoria básica, documentos, control cotidiano del PC y hasta tres proyectos.

¿Qué añade Max?

Visión, coding completo, Docker sandbox, workflows, programación, mensajería, compañeros móvil/navegador y servidores MCP, según disponibilidad.

¿Es open source?

No. O.A.S.I.S. es software propietario. El repositorio público contiene documentación, releases y transparencia.

¿Dónde reporto errores?

En GitHub Issues, incluyendo versión, Windows, hardware, modelo y pasos para reproducir.
