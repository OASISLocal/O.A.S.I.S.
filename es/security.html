Inicio / Seguridad

La IA pide permiso antes de actuar.

Cada herramienta declara su riesgo. Las acciones de mayor impacto requieren confirmación explícita y no deben ejecutarse silenciosamente.

NivelEjemplosControl
BajoConsultar CPU, RAM o buscar archivosAutomático
MedioEscribir archivos o modificar portapapelesPermitir, denegar o preguntar
AltoEjecutar código o workflowsConfirmación
CríticoControl del sistema, matar procesos o limpiar datosConfirmación explícita cada vez

La aplicación sigue siendo software beta: revisa resultados importantes y reporta comportamientos inesperados en GitHub Issues.
