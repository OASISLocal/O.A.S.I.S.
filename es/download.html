Inicio / Descargar

Descarga Personal.

Gratis, sin cuenta y para Windows 10/11 x64. La aplicación necesita red para descargar el instalador y el modelo; las funciones locales compatibles pueden funcionar después sin conexión.

Descargar desde GitHubVer requisitos

INSTALACIÓN

Tres pasos.

1

Instala

Ejecuta el instalador de la release más reciente.

2

Descarga un modelo

Abre Models y elige un perfil compatible, como Gemma, Qwen o Llama.

3

Prueba una tarea

Busca un documento, resume una nota o consulta el estado del PC.

Verifica antes de ejecutar.

Las releases publican sus hashes cuando están disponibles. En Windows puedes comprobar un archivo con certutil -hashfile OASIS.exe SHA256.

Consulta el historial de releases y abre un issue si encuentras un problema reproducible.
