Inicio / Descargar

Consigue la beta. Quédate con tus datos.

OASIS es gratis para Windows 10 y 11, sin cuenta y sin límite de tiempo. Descarga el instalador desde GitHub Releases y verifica su checksum si quieres. Instálalo, descarga un modelo de IA y listo.

Descargar para Windows Ver requisitos

Verifica primero

Confía, pero verifica.

Cada versión incluye un hash SHA256. En Windows, abre un terminal y ejecuta:

certutil -hashfile OASIS.exe SHA256

Compara la salida con el hash publicado en la página de la versión. Si no coincide, no lo instales, y avísanos en Incidencias.

Después de instalar

Tres pasos hasta sin conexión.

1

Abre la app

El primer arranque sugiere un modelo acorde a tu hardware. Acéptalo o elige otro.

2

Descarga el modelo

Una descarga con pausa y reanudación. Es lo último que necesita internet.

3

Desconecta y habla

En serio: pruébalo con el router apagado. Chatea, dicta, pídele que recuerde algo.

Antes de empezar, asegúrate de tener: Windows 10/11 · 8 GB de RAM o más · ~10 GB libres de disco para la app y los modelos · internet solo para las descargas iniciales · Docker Desktop solo si quieres ejecución de código. Primer modelo para probar: Gemma 4 (Q4, ~4 GB).

¿Atascado? Las preguntas frecuentes cubren lo habitual; Incidencias cubre el resto — incluye tu versión de Windows y tu modelo.
