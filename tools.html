Home / Tools

Dozens of tools, with exactly how each behaves.

Every tool declares a risk level, a plan and whether it stays on your PC. Low-risk reads run automatically. High-impact tools always ask for confirmation, in every plan. P = Personal · M = Max · Net = uses the network when you invoke it.
