Glossary

The words we use, defined.

77 terms. Every definition below is the same text that appears as a tooltip on the pages that use the term. No marketing words.

What the AI is

TermWhat it means here
Embedding A numeric representation of meaning. It lets the assistant compare pieces of text by what they mean, not just the words used. Details
Hallucination ES: Alucinación A fluent, confident answer that is simply not true. It happens because the model predicts what would read well, and there is no database inside it to check against. Details
Inference ES: Inferencia The moment a model actually produces an answer from your input. On a local assistant it happens on your PC, using your CPU or GPU. Details
LLM Large Language Model — the kind of AI model that reads and writes text. Local models are smaller versions you can run yourself. Details
Local AI ES: IA local An AI assistant that runs its model on your own computer instead of sending your data to a server. You keep control of the model and the files. Details
Local inference ES: Inferencia local Running the AI model on your own hardware, rather than on a remote server. The response is produced on your machine. Details
OCR Optical Character Recognition — reading text out of an image or a screenshot so the assistant can act on it or copy it. Details
On-device ES: En el dispositivo Work handled by your own computer's hardware instead of a remote server. Audio, images and text never have to leave the machine. Details
Semantic search ES: Búsqueda semántica Search that looks for meaning and related concepts rather than only exact words. Useful when you remember the idea but not the wording. Details
Speech recognition ES: Reconocimiento de voz Turning your spoken words into text. O.A.S.I.S. does this on your PC, so dictation works without sending audio anywhere. Details
Training ES: Entrenamiento Showing a model an enormous amount of text and nudging its numbers a little every time its guess was wrong. Nobody writes the grammar or the facts: they come out of the statistics. Details
Speech synthesis ES: Síntesis de voz Turning text into spoken audio. It lets the assistant answer out loud, in Spanish or English, using voices on your machine. Details
Vision ES: Visión The ability to look at an image or your screen and describe what is there. It only happens when you ask. Details
Voice cloning ES: Clonación de voz Building a synthetic voice from a sample so replies sound like a chosen speaker. A Max feature, created from audio you provide yourself. Details
Wake word ES: Palabra de activación A short phrase that starts listening without touching the keyboard. Recognition runs locally, so the microphone is not streamed anywhere. Details

Models and files

TermWhat it means here
Context window ES: Ventana de contexto How much text the model can consider at once. Larger windows let it handle longer documents and conversations. Details
GGUF A model file format commonly used for running AI models locally. It packages a model into a single file your PC can load. Details
Hugging Face A large public catalogue of AI models. The app searches it so you can pick a compatible model and download it without hunting for files. Details
Knowledge cutoff ES: Corte de conocimiento The date of the newest text the model was trained on. It cannot know anything published after it, and it will not warn you on its own. Details
Model ES: Modelo The AI 'brain' — a large file that has learned patterns from text. You download one and it runs on your computer. Details
Model file ES: Archivo de modelo The single file a model ships as. Choosing which model runs means choosing which file sits on your disk, which is why a local assistant can work with the network unplugged. Details
Open weights ES: Pesos abiertos A model whose trained numbers are published so anyone can download them. The training code usually is not, which is why this is not the same as open source. Details
Parameters ES: Parámetros The numbers inside a model that training adjusts. '7B' means seven billion of them. They are the model: there is nothing else in there. Details
Quantization ES: Cuantización A way of compressing a model so it uses less memory and runs faster, at a small cost in quality. Q4 is a common middle ground. Details
Sampling ES: Muestreo The step where one of the possible next tokens actually gets picked. The model only produces probabilities; the application around it does the choosing. Details
Temperature ES: Temperatura A setting that decides how often an unlikely word is allowed. Low is repetitive and safe, good for code. High is more varied and more likely to be nonsense. Details
Token A small chunk of text — roughly part of a word — that the model reads and writes. Speed is usually measured in tokens per second. Details
Tokenizer ES: Tokenizador The step that cuts your text into tokens before the model sees it. It also decides the price of a request, because cost is counted in tokens. Details

Hardware

TermWhat it means here
CPU The main processor of your computer. It can run small AI models on its own, just more slowly than a graphics card. Details
GPU A graphics card. For AI it acts as an accelerator, producing answers noticeably faster than the CPU alone. Details
Model size ES: Tamaño del modelo Usually written like '7B' — billions of parameters. Bigger models know more but need more memory and run slower. Details
Offloading Splitting a model between your graphics card and your processor so it fits in the memory you have available. Details
RAM Your computer's working memory. It holds the model while it runs, so more RAM lets you load larger models. Details
VRAM Memory available on a graphics card. Larger local models generally need more VRAM when running on the GPU. Details

Software and formats

TermWhat it means here
API A defined way for two programs to talk to each other. Here it usually means the local interface other tools use to reach O.A.S.I.S. Details
Local database ES: Base de datos local The file on your disk where memory is stored — messages, notes and documents, indexed so they can be found again by meaning. Details
Docker A tool that runs software in isolated containers. O.A.S.I.S. uses it to execute generated code safely, and it is optional. Details
EULA End User Licence Agreement — the terms you accept to install and use the app. It ships with the installer and covers one Windows machine. Details
SHA-256 hash ES: Hash SHA-256 A short fingerprint of a file. Comparing it with the published value proves the installer you downloaded is the one that was released. Details
llama.cpp A widely used local runtime that loads GGUF models and runs them efficiently on CPUs and GPUs. It is the engine under many local AI tools. Details
LM Studio A desktop app for downloading and chatting with local models. Excellent for a chat window; it does not drive your PC or keep a memory of you. Details
MCP A protocol that lets AI systems connect to external tools and services in a standardised way. It is how O.A.S.I.S. can use outside tool servers. Details
Ollama A popular way to run local models from a command line. It is strong as a model server; O.A.S.I.S. is the assistant layer around a model. Details
Open source ES: Código abierto Software whose source code is published for anyone to read and modify. O.A.S.I.S. is not: it is proprietary, with a public changelog instead. Details
Proprietary ES: Propietario Software whose source code is not public and is licensed by its owner. The app is proprietary; the AI models you run are licensed separately. Details
Repository ES: Repositorio The public project folder on GitHub, where releases, the roadmap and the changelog live. Details
Runtime The engine that actually loads a model file and produces answers. It is what turns a downloaded file into a working assistant. Details
Tool server ES: Servidor de herramientas An external service that offers extra tools to the assistant. You add it yourself, so it only runs when you configure it. Details

Security and permissions

TermWhat it means here
Analytics ES: Analítica Scripts that count visitors and behaviour. This site runs none, and the app has no analytics built in — there is nothing to opt out of. Details
Action log ES: Registro de acciones A local record of what the assistant did, kept on your machine so you can review or undo recent actions. Details
Encryption ES: Cifrado Scrambling stored data so only someone with the key can read it. Secrets and the local vault are encrypted on your machine. Details
High-impact action ES: Acción de alto impacto An action that can change or remove things — like deleting files, running code or shutting down. These always ask for confirmation first. Details
Isolation ES: Aislamiento Keeping an action inside its own contained environment, with limits on what it can read, write or reach. Details
Permission ES: Permiso Your per-tool setting that decides whether an action runs automatically, asks first, or is blocked. You can change it at any time. Details
Sandbox An isolated environment used to run code with additional safety boundaries, so generated code cannot reach the rest of your system. Details
Telemetry ES: Telemetría Usage or crash data sent back to the maker. Here it ships off: nothing is reported unless you deliberately enable an outbound channel. Details
Vault ES: Caja fuerte The encrypted store for secrets such as API keys and tokens. It lives on your disk, not in a cloud account or a plain config file. Details

Network and services

TermWhat it means here
Cloud ES: Nube Computing that runs on someone else's servers over the internet. Here it is the alternative the app is built to avoid for everyday tasks. Details
Endpoint A specific address a program can send requests to. With telemetry off, there is no endpoint receiving your data by default. Details
Integration ES: Integración A connection to an outside service, like a messaging platform. It only communicates when you enable and use it. Details
Localhost Your own machine as seen by itself. The app's internal server listens there, so nothing is exposed on your network. Details
Network features ES: Funciones de red The optional parts that reach the internet, such as web search and integrations. They only communicate when you use or configure them. Details
Server ES: Servidor A remote computer that answers requests. A local assistant avoids depending on one for chat, voice or memory. Details
Webhook A URL that receives a message when something happens. O.A.S.I.S. only uses one if you set it up for diagnostics. Details

The product and its plans

TermWhat it means here
Agent ES: Agente An assistant that does more than answer: it plans, uses tools, asks for permission and verifies the result. Details
Browser extension ES: Extensión de navegador A Max add-on that lets the browser talk to your assistant on the same PC, so it can work with the page you are looking at. Details
Companion Optional apps that reach your assistant from elsewhere — phone, browser or chat platforms — over your own network. Details
Local-first Designed to keep local tasks and data on your PC, while still allowing optional network-enabled features when you choose to use them. Details
Max The paid edition: advanced coding, sandboxed execution, workflows, integrations and companion apps. A one-time payment, not a subscription. Details
Memory ES: Memoria What the assistant keeps between conversations — facts, notes and documents — stored on your disk and searchable by meaning. Details
Offline ES: Sin conexión Supported local features can work without internet after a model is downloaded. Network-enabled features require connectivity when used. Details
Offline-first Built so the core experience works without a connection, and network access is an extra you opt into — not a requirement to function. Details
Persistent memory ES: Memoria persistente Information that survives after the conversation ends, so you don't have to repeat yourself every time. Details
Personal The free plan: local chat, voice, memory, documents and everyday PC control, with no account and no message limits. Details
Skill A small piece of behaviour triggered by your phrases, so common requests get handled your way. Details
Tool ES: Herramienta A single capability the assistant can use — reading a file, changing the volume, setting a timer — each with its own permission level. Details
Workflow A routine you describe in plain words, like 'every day at 9 send me a briefing', that runs on a schedule. Details
