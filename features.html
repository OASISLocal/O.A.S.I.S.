Full spec sheet, no adjectives.

The full spec sheet: current beta capabilities are separated from planned Max features. No adjectives necessary.

Models

The brain downloads separately.

OASIS ships without a model: you pick one in GGUF format — the open file format these models ship in — from inside the app (it searches Hugging Face, downloads with pause and resume) and it runs on your machine via llama.cpp. A small Gemma or Qwen is a fine start. With an NVIDIA GPU with 4 GB or more it flies; on CPU it still gets there.

Families
Llama, Gemma, Qwen, DeepSeek, Phi, Mistral — and any GGUF you hand it.
Languages
Spanish and English, across interface, chat and voice.
Personalities
OASIS, TARS, NOVA and REBELDE. The last one is sarcastic, with limits you set yourself.

What it can do

100 tools, grouped so they make sense.

Talk & listen
Dictation and read-aloud in Spanish (faster-whisper and Kokoro/Piper voices), wake word, background-noise filtering.
Remember
Conversation memory, notes and saved facts, plus indexed PDF, DOCX, XLSX and code — all on your disk.
Drive the PC
Volume, windows, opening apps, Spotify, screenshots, weather, calculator, timers, clipboard, shutdown. Each asks its own permission.
See
Looks at your screen or an image and describes it; can click by coordinates, region or recognized text.
Code
Explains code and — with Docker installed — tests it in an isolated sandbox before touching anything of yours. Up to three automatic retries.
Automate
Scheduled workflows in plain words ("every day at 9"), proactive nudges and small trigger-based skills.
Connect (Max)
Your own Discord or Telegram bot with voice, an Android app over local network with QR pairing, and a browser extension.

The exact list lives in the code (core/tools/registry.py). This page summarizes; the code rules.

Requirements

The minimum for it to run well.

  • Windows 10 or 11. Everything else comes later.
  • Any modern CPU for small models; GPU recommended, not required.
  • Docker Desktop, only if you want it to run code.
  • Internet, only to download the app and a model. Afterwards, optional.

Editions

One free, one single payment.

Personal, free: chat, local voice, memory, documents, everyday PC control and core tools. No account, no message limits. Projects up to 3.

Max, planned as a single payment (€15 early access, €25 at 1.0): vision and screen analysis, full coding with isolated Docker sandbox, workflows and scheduling, Discord/Telegram, Android app, browser extension, external MCP tool servers, voice cloning and advanced memory. These features are planned, not available in the current public beta; join the waitlist and we'll email you once when Max opens.
