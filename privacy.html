Local-first. Precisely.

Local features run on your PC. Network-enabled features communicate externally only when you use or configure them. O.A.S.I.S. is offline-first, not network-blind. No analytics, no cookies, no accounts, no telemetry. This page separates what stays local from what can use the network.

Network tools only reach the internet when you invoke them. There is no silent background syncing.

This website

What this site knows about you: nothing.

  • No analytics. No Google Analytics, no Plausible, no pixels. We count nothing.
  • No cookies. The only thing stored in your browser is your light/dark preference, on your device only.
  • Optional same-site fetches: glossary data and launch configuration are loaded from this site. The GitHub star count calls GitHub's public API — your browser talks to GitHub, not to us.
  • No third-party requests on normal page load. Fonts and site data are served from this site. The optional GitHub request degrades silently if blocked.
  • Waitlist exception. If you join it, Cloudflare KV stores your email, interests and join date only for the launch email. Request deletion at hello@oasislocal.dev; deletion removes the stored entry.

The desktop app

What the app stores, and where.

  • No telemetry, no crash reports, no accounts. There is no endpoint that receives them by default.
  • Localhost only. The app's internal server binds to your machine; nothing listens on your network.
  • Per-tool permissions. Microphone, screen and files each have their own switch in Settings — revocable anytime.
  • Your data, your folder. Models, memory and settings live in %LOCALAPPDATA%\O.A.S.I.S.\. Delete it and it's gone.
  • Encrypted vault, PIN lock, action log for whoever shares a machine or just sleeps better.
  • Optional diagnostics. The only outbound channel that can be enabled is a diagnostics webhook you configure yourself.
  • App privacy ≠ website privacy. This page describes both, separately, on purpose.
