Home / FAQ

Questions, answered straight.

These are the questions people actually ask before installing a local AI assistant — collected from early testers and GitHub issues, not invented by marketing. Short answers, no fog.

What is a local AI assistant?

A program that runs its AI model on your own hardware instead of calling a server. OASIS runs entirely on Windows PCs: chat, voice, memory and tools keep working with no internet after a one-time model download.

Does it really work offline?

Yes. Install the app, download one model, then unplug the router and try everything: chat, dictation, reminders, file tools. It all stays the same — because nothing ever left your PC.

Do my files leave my computer?

No. No telemetry, no accounts, no analytics. Your stuff lives in %LOCALAPPDATA%\O.A.S.I.S.\, the server binds to localhost only, and mic, screen and files each have their own permission switch. Read the full privacy page.

What PC do I need?

Any modern CPU runs small models well. The comfortable setup is 16 GB RAM plus an NVIDIA GPU with 4 GB or more for 7–8B models. Details and honest caveats on the requirements page.

Is there a Mac or Linux version?

Not yet — Windows 10/11 only. Linux and macOS are on the public roadmap; the models themselves are portable, the packaging isn't done.

How is it different from Ollama or LM Studio?

Those are excellent at running local models. OASIS is the layer that turns them into an assistant: offline voice, persistent memory, 68 PC tools, scheduled routines, Discord/Telegram. Full table on the comparison page.

Is OASIS Max a subscription?

No. One payment — €15 in early access, €25 once 1.0 ships. No recurring fees, no per-message limits.

How do I uninstall it?

Like any Windows program — plus deleting one data folder removes models, memory and settings. Nothing stays in a cloud, because nothing ever went there.
