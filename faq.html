Questions, answered straight.

These are the questions people actually ask before installing a local AI assistant — collected from early testers and GitHub issues, not made up for marketing. Short answers, no fog.

Common questions

What is a local AI assistant?

A program that runs its AI model on your own hardware instead of calling a server. OASIS runs on your Windows PC: chat, voice, memory and local tools keep working with no internet after a one-time model download.

Does it really work offline?

Local chat, voice, memory and other local workflows keep working without an internet connection once the models are installed. Features such as web search, weather and external integrations need network access when you use them. In short: offline-first, not network-blind.

Do my files leave my computer?

No. No telemetry, no accounts, no analytics. Your stuff lives in %LOCALAPPDATA%\O.A.S.I.S.\, the server binds to localhost only, and mic, screen and files each have their own permission switch. Read the full privacy page.

What PC do I need?

Any modern CPU runs small models well. The comfortable setup is 16 GB RAM plus an NVIDIA GPU with 4 GB or more for 7–8B models. Details and honest caveats on the requirements page.

Is there a Mac or Linux version?

Not yet — Windows 10/11 only. Linux and macOS are on the public roadmap; the models themselves are portable, the packaging isn't done.

How is it different from Ollama or LM Studio?

Those are excellent at running local models. OASIS is the layer that turns them into an assistant: offline voice, persistent memory, 100 PC tools, scheduled workflows, Discord/Telegram. Full table on the comparison page.

Which features need Max?

Personal covers chat, voice, memory, documents and everyday PC control. Max adds vision/screen analysis, full coding with the Docker sandbox, workflows and scheduling, Discord/Telegram, the Android app, the browser extension, external tool servers and voice cloning. The pricing matrix lists every feature.

Is OASIS Max a subscription?

No — and there's nothing to pay yet. Max will be a single payment (€15 in early access, €25 at 1.0), never a subscription. Join the waitlist and we'll send one email when it opens.

What happens when an action is dangerous?

It stops and asks. Deleting files, shutting down or running code always requires your explicit confirmation. How security works →

Can it access my screen?

Only when you ask it to look — for example, to describe a window or click something for you. It never watches in the background.

Is O.A.S.I.S. open source?

No. It's proprietary software with a public changelog and roadmap — the source code is not publicly available. See the EULA shipped with the installer.

How do I uninstall it?

Like any Windows program — plus deleting one data folder removes models, memory and settings. Nothing stays in a cloud, because nothing ever went there.
