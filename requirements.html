Home / Requirements

Will it run on your PC? Probably yes.

Any modern CPU runs small AI models; a GPU just makes them faster. There is no minimum GPU, no subscription gate, no cloud fallback. Pick the tier that matches your machine — the app recommends a model for your hardware on first launch.

TierHardwareWhat you get
MinimumModern quad-core CPU · 8 GB RAM · 10 GB free disk · Windows 10/11Small models (1–4B params). Accurate answers at a slower pace. Voice works.
Recommended6+ core CPU · 16 GB RAM · NVIDIA 4–8 GB VRAM7–8B models in Q4 quantization. Fluid chat, fast transcription, vision included.
OptimalRecent CPU · 32 GB RAM · NVIDIA 12 GB+ VRAMLarger models, everything at once: voice, vision, memory indexing and code sandbox.

Models & sizes

How big is a brain, exactly?

Models download once, then live on your disk. Approximate sizes for the popular quantized (Q4) builds:

Size classDownloadNeedsFeels like
1–3B~1–2 GBAny CPUSnappy drafts, reminders, simple Q&A.
7–8B~4–5 GBCPU ok · GPU betterThe sweet spot: daily assistant work.
13–14B~8–10 GB16 GB RAM or 8 GB VRAMDeeper reasoning, slower without GPU.

Families available: Llama, Gemma, Qwen, DeepSeek, Phi, Mistral — plus any GGUF file from Hugging Face. Sizes vary by quantization; the app shows exact numbers before downloading.

Honest notes

What we'd rather tell you now.

  • CPU-only is genuinely usable for chat, voice and memory — just don't expect 50 tokens/sec from an 8B model.
  • Laptops run warm. Sustained inference is a workout; plug in, and the app's CPU/GPU-layer settings help.
  • Docker is only for code execution. Skip it and everything else still works.
  • Internet is needed twice: downloading the app and the model. Afterwards it's optional — test it with the router off.
  • Windows 10/11 only for now. Linux and macOS builds are on the roadmap, not in the download folder.
