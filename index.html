It remembers, so you don't have to.

What you tell it, it keeps: conversations, notes, facts you ask it not to forget. It also reads your documents — PDFs, Word, Excel, code — and answers citing the exact file each fact came from. All in a database on your disk.

  • Real memory: facts, notes and conversations, searchable by meaning.
  • Your documents as a source — every answer shows where it came from.
  • Deletable: by memory, by type or by file, whenever you want.

It codes carefully.

Paste an error and get a plain-words explanation. Ask for a script and it writes it, tests it in an isolated sandbox, and shows you the diff before touching your files. If it fails, it retries on its own — up to three times.

  • Explains repos and errors without the jargon.
  • Runs in a sandbox first — nothing executes on your system without your OK.
  • Diffs before applying: review every change line by line.

It sees your screen — only when asked.

OASIS looks only when you tell it to — and understands what it sees: it describes images, reads your screen, clicks where you point. It also drives your PC: volume, windows, Spotify, timers, clipboard. Every permission has its own switch in Settings.

  • Local vision: describes your screen or any image.
  • Drives your PC: apps, windows, audio, system.
  • Per-tool permissions: mic, screen and files, each with its own off switch.

Download

Up and running in ten minutes.

1

Install the app

From GitHub Releases, for Windows 10/11. Verify the SHA256 if you're meticulous: certutil -hashfile OASIS.exe SHA256.

2

Download a model

In the Models tab, pick a small Gemma or Qwen and hit download. Once, with internet. After that, you don't need it.

3

Talk

Type or press to speak. Ask it to tidy Downloads, explain an error, or remind you about the dentist.

Requirements: Windows 10/11 · any modern CPU (NVIDIA GPU recommended, not required) · Docker only if you want it to run code. Spanish and English included. Keyboard-only friendly, scalable text, screen-reader compatible.

Questions

What people ask before installing.

Does it really work offline?

Yes. After installing the app and downloading a model, unplug your router and try it: chat, dictate, ask it to remember something. Everything stays the same — because nothing ever left your PC.

Do my files leave my computer?

No. No telemetry, no accounts, no analytics. Your stuff lives in a local folder, the server listens on localhost only, and every tool has its own permission switch in Settings.

What PC do I need?

Any modern CPU runs small models. An NVIDIA GPU with 4 GB or more makes it much snappier. Docker Desktop is only needed if you want it to run code in a sandbox.

What about Mac or Linux?

Not yet — Windows 10/11 only. Linux and macOS are on the roadmap, and the installer already prepares per-platform builds.

Is Max a subscription?

No. One payment: €15 in early access, €25 once 1.0 ships. No fees, ever.
